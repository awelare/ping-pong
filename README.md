# Classic Pong Game
Простая и увлекательная игра Pong на языке Python с использованием библиотеки pygame
# Требования
Убедись что у тебя установлен Python 3.x и библиотека pygame

pip install pygame
# Управление
игрок 1 (лево) W - вверх, S - вниз
игрок 2 (лево) стрелка вверх - вверх, S - стрелка вниз
